# Share assets

Download the videos from the [latest GitHub release](https://github.com/abnerhorn/tab-palette/releases/latest):

- `tab-palette-demo-x.mp4`: 1620 × 882, 30 fps, H.264, silent, ready to attach to a post.
- `tab-palette-demo-master.mp4`: native 3240 × 1764 master, 30 fps, H.264, silent.
- `tab-palette-demo-master.webm`: native 3240 × 1764 VP9 version.
- `tab-palette-demo.png`: native 3240 × 1764 poster.

The film runs for 19 seconds. It demonstrates Cmd+T, ordered tab shortcuts, filtering with inline completion, selecting an existing tab with Cmd+1, and opening a typed URL. The source and [storyboard](../demo/provenance.md) are included in this repository. Browser contents are sample fixtures, with local public-brand icons and an original wallpaper.

The smaller MP4 is derived from the native master with Lanczos downsampling, not by enlarging a screen recording. X’s published [video guidance](https://help.x.com/en/using-x/x-videos) was checked when preparing it. As with any social platform, the service may recompress an upload.

Suggested post:

> I missed Arc’s ⌘T in Chrome, so I made Tab Palette.
>
> Open tabs in order. ⌘1, ⌘2… to jump. Type to filter tabs, open a URL, or search.
>
> Open source, with manual setup and a prompt you can give your agent:
> https://github.com/abnerhorn/tab-palette

The videos are kept in release assets rather than Git history. Raw frames and local capture/export metadata are ignored; those metadata files can contain machine-specific paths.
